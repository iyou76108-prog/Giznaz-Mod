# Гизназ — Forge 1.21.1

Исходный проект мода для Minecraft Java Edition **Forge 1.21.1** (Java 21).

## План функций

- Свиньи с лицом Гизназ на текстуре головы, при этом сохраняются модель, AI, звуки и поведение свиньи.
- Персонаж/моб Гизназ появляется около деревень.
- Анимация приседания перед действием.
- Бросаемый шуточный снаряд, который взаимодействует с мобами.
- Подбираемый предмет и удобрение для ускорения роста культур.
- Рецепт удобрения.

## Сборка

Требуется JDK 21 и Gradle 8.8 или совместимая версия ForgeGradle 6.

```bash
gradle build
```

Готовый JAR будет в `build/libs/`.

## Статус

Это начальный каркас проекта. Игровые механики, кастомная текстура свиньи и анимация ещё не реализованы и не должны считаться готовыми. Для текстуры используем присланное изображение как исходник; перед публикацией проверьте, что в репозитории допустимо размещать эту фотографию.
