# Гизназ — Minecraft Forge 1.21.1

Мод для Minecraft Java Edition 1.21.1, Forge 52.x и Java 21.

## Реализовано в текущей версии исходников

- Предмет «Какашка Гизназа», который можно подобрать.
- Удобрение на основе костной муки: ускоряет рост растений.
- Рецепт: 1 какашка + 1 костная мука = 2 удобрения.
- Зарегистрирован моб Гизназ с базовыми характеристиками и поведением.
- При появлении жителей в мире есть шанс появления Гизназа поблизости; в радиусе деревни поддерживается не более одного такого моба.
- Гизназ ищет ближайших существ (не жителей и не других Гизназов), приближается и бросает в них какашки.
- Перед естественным испражнением Гизназ приседает; после анимации появляется подбираемая какашка.
- Снаряд наносит небольшой урон и оставляет какашку для подбора.

## Что ещё не завершено

- Персональная текстура Гизназа и наложение лица на морды свиней. Файл `111.png` лежит в корне репозитория, но GitHub-интеграция не отдаёт байты PNG, поэтому сейчас нельзя безопасно преобразовать именно эту фотографию в игровые текстуры.
- Проверка полной сборки и запуск в клиенте Minecraft. GitHub Actions автоматически собирает проект после каждого коммита; статус сборки нужно проверить перед выпуском JAR.

## Сборка

Нужен JDK 21. Запусти:

```bash
gradle build
```

Готовый мод будет в `build/libs/`.

## Установка

Скопируй собранный `Giznaz-Mod-1.0.0.jar` в папку `.minecraft/mods` вместе с Forge 1.21.1.
