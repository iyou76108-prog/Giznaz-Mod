# Гизназ — Forge 1.21.1

Исходный проект мода для Minecraft Java Edition **Forge 1.21.1** (Java 21).

## Уже добавлено в проект

- Предмет «Какашка Гизназа» (пока обычный подбираемый предмет без броска).
- Предмет «Удобрение Гизназа», основанный на механике костной муки: применяет стандартное ускорение роста.
- Рецепт: 1 какашка + 1 костная мука = 2 удобрения.
- Русские и английские названия и модели предметов.

## Что ещё предстоит реализовать

- Моб Гизназ, появляющийся возле жителей в деревнях.
- Анимация приседания/испражнения.
- Бросок какашек в ближайших существ.
- Замена морд свиней на лицо Гизназа с сохранением поведения свиней.
- Настоящие текстуры и модели моба/снаряда.

## Сборка

Требуется JDK 21 и Gradle 8.8 или совместимая версия ForgeGradle 6.

```bash
gradle build
```

Готовый JAR будет в `build/libs/`.

## Статус

Это ранняя реализация предметов и рецепта. Полный игровой функционал ещё не готов, а сборка пока не подтверждена успешным запуском GitHub Actions. Фото по присланной ссылке VK недоступно для загрузки в текущей среде, поэтому личное лицо пока не встроено в текстуры.
